# r16 editable Kit1 sources

Seven source-derived Blender studies and their GLB exports, copied from the
studies actually used in the r16 playtest delivery. Each model directory keeps
its exact `author.py` version, `native_kit_profiles.json`, `.blend`, `.glb`,
vertex/source report and historical candidate receipt. The reports' external
candidate paths identify original stages; do not infer visual approval from
their existence. The source author accepts `-- REPO FRESH_OUTPUT MODEL --levels 1`.

Use `tools/street-cars-wave2/package_fitted_car_kits.py` to adapt a fresh study
into a private runtime copy. Outback's later kit2 grey-skirt UV-only correction
is separate: `tools/street-cars-wave2/correct_outback_skirt_uv.py`. The corrected
future skirt author is `build_outback_safe_skirts.py`; historical r14 sources
remain in their original directory for provenance.

First-wave Sport1 sources are under
`mods/street-cars/tools/assets/sport1-20261031`. Runtime ZIPs exclude authoring
tools. Deployment and remaining acceptance limits are documented in
`docs/ten-car-rp5-playtest-2026-10-31.md`.
