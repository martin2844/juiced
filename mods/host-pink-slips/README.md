# Host Pink Slip Races

Enable the package and restart OpenJuice. Choose an empty future date in the
career calendar, host an event, and change Type past Sprint to **PINK SLIPS**.
Opponent lists only rival crews with at least **600 respect** and a car matching
the selected class/criteria. Change class/criteria if none can participate.

Choose the opponent in setup; the race setup also lets you cycle eligible rivals
and choose the route and laps. A pink-slip event is one player versus one rival,
one car each, with no cash prizes or entry/hosting fees. The player must own an
eligible car and have garage space for a win. The normal confirmation and betting
flow stakes your selected car: winning takes the rival's car; losing costs yours.
Respect is rechecked before creating the event. Regular hosted races retain their
original requirements. Existing pink-slip events remain playable after disabling
the mod; disabling removes the option to create new ones.

Requires the native host-pink-slips engine support (Android .7 or corresponding
source). This is offline career hosting, not online multiplayer.
