# Crew Pink Slip Races

Enable and restart. With a recruited teammate, enter a career pink-slip event,
choose yourself or one teammate in SELECT DRIVERS, then choose the garage car
that driver will risk. The existing title confirmation still applies.

This is a one-on-one duel: your teammate races instead of you, while you watch
and can issue crew intensity commands. Winning adds the rival car to your garage;
losing removes the selected car. No extra cars, money or respect are granted.
Hosted events still require the Host Pink Slip Races package and 600 respect;
this package also supports ordinary career pink-slip invitations.

Requires native Crew Pink Slip engine support. Disabling restores player-only
driver selection. No save format or roster changes. The existing pink-slip
pre-race autosave stakes the car before racing; quitting/crashing after accepting
can therefore cost that car, just as in the base game.
