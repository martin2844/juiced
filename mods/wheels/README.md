# Eagle Ultimate Wheels

Adds 128 wheels after the original 74 and 40 wheel colours. The package works with
or without Ferrari. Enable it in **Options → Mods**, restart, then use the normal
wheel suppliers in the garage.

- `assets/`: imported meshes, materials, textures and the author's original README.
- `patches/`: appended wheel catalogue and wheel colours, built from the owner's game.
- `tools/`: archive importer and the native fit/blur/save validation program.

Meshes include the vertex colour and secondary UV declarations needed by Metal.
Stock wheels and tyre choices remain unchanged. Credit: **Eagle**; original credits
and instructions are in `assets/EAGLE-README.txt`. The wheel pack remains third-party
content; the repository's code licence does not relicense it.

Disabling wheels selects a separate career directory so saved imported wheel
indices are not loaded against the stock catalogue. Re-enable to resume those saves.
