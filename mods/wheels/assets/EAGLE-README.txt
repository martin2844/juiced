
	Use Jatool to unpack your scripts.dat, ui.dat, then rename or remove it.
	Backup wheels.txt from scripts folder.
	Drop the files from mod juiced folder into your juiced folder.
	Copy entries from extra wheel colors.txt to the original cardefs.txt (at the end of file) in game scripts folder, if you need more color options.

	I recommend to use tyres.txt from mod (scripts folder), it changes proto tire brand to toyo tires, so it won't be two same decals when using yokohama rims and tires.
	
	
	
	
	There is also an option to change brake rotor texture.
	to do it, in carmesh/mats open brake_A.pmd with notepad, and change texture name "addon_brake_B.ddt" to other variant.
	(names and example pics are in mod folder, just change letter from A to F, can do while alt tab, to apply changes reenter garage)
