now installed and enabled through a separate overlay; see [Linux mods](linux-mods.md).

The Linux launcher reads `~/Projects/juiced/game-data`.
Every regular file in that installation was compared by SHA-256 against its
counterpart in `~/Projects/juiced/installers/Juiced.zip` (the `Juiced/` directory).

- 1,615 files identical.
- One file different: `crash.txt`, a runtime crash report.
- No missing files.
- No extra files.

No additional car, track, texture or script mods have been installed on top of
this local installation archive. There is no additional mod-loader file in the
active data directory. Updating the engine source does not install asset mods.
The `plugins` directory is empty; the original Windows DLLs are not loaded by
the native executable.

This is an audit against the retained installer, **not** a certification that
that installer is an unmodified retail dump. Establishing that would require
an independently verified retail manifest. It cannot rule out modifications
already included in the ZIP before we received it.

The unofficial patch 1.02.5 is the updated engine base; its bug fixes and support
for additional parts are not the same as installing community car/texture packs.
