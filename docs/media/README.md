# README screenshots

These are actual native runtime captures, converted to opaque RGB JPEG and
resized for the repository front page. Their capture dates, platforms, scenes,
dimensions and SHA256 hashes are recorded in [captures.json](captures.json).

The Linux races and garage views were captured on 3 November 2026 from the
current OpenJuice 1.02.7 native renderer. The close garage views use the actual
CarView viewport with its 2D selector UI hidden. The poker view uses a synthetic
test career so that no user's career or money is changed for the screenshot.

The Metal race was captured from the installed Mac application during the same
day's validation. The Retroid race and launcher are physical-device screen
captures. The touch editor image is from the individual-button sizing validation
on 25 October; its original capture date is retained in the manifest.

Engine: [OpenJuice by Sidewinder / sidecr3w](https://gitlab.com/sidecr3w/openjuice).
Juiced game imagery belongs to its respective rights holders. These screenshots
are documentation of the port; players must supply their own game data.
